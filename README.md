# Kobold Quest

A 2D-style adventure game with 3D voxel characters, built with [Godot 4](https://godotengine.org/).

## Getting started

1. Install Godot 4.5 or newer.
2. Open Godot, choose **Import**, and select this folder's `project.godot`.
3. Press **F5** to run.

## Controls

| Action | Key |
| ------ | --- |
| Move   | W A S D |

## Project layout

